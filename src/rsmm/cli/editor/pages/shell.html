RSMM Editor

Welcome to the RSMM Editor

Make Ravenswatch mods without writing code. Nothing touches the game until you apply a mod.
  1. Pick what to change in the tabs at the topItems, Talents, Scripts, Hero, Abilities and Map are separate editors. A dot on a tab means it has changes you have not saved yet.
  2. Edit an item, or make a new oneOpen an item and choose Edit to change the game's own, or New item from it for a separate copy. + New custom item starts one for you.
  3. Watch the cardThe preview is drawn with the game's own art and follows every change you type.
  4. Save to a modThe bar at the bottom collects every change. Add to mod writes them; rsmm apply puts the mod in the game.
