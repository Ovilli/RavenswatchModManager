Contributing to Ravenswatch Mod Manager
=====================================

Thank you for contributing! This guide explains how to report issues and submit pull requests.

Report issues
- Search existing issues first.
- Provide reproduction steps, OS, game version, and relevant logs.

Code style
- Follow existing formatting in `src/` and `rsmm/`.
- Use `clang-format` for C++ and `black` for Python where applicable.

Pull requests
- Fork the repo and create a focused topic branch.
- Include a clear description, related issue, and testing steps.

Tests and CI
- Add tests for new logic where practical.
- Ensure CI passes before requesting review.

Communication
- Be responsive to review comments and keep PRs small.

Support the project
- RSMM is free and MIT-licensed; there is no paid tier and nothing is held back for donors.
- If you would rather chip in than file a PR: [ko-fi.com/ovilli](https://ko-fi.com/W7W41FW3YE).
