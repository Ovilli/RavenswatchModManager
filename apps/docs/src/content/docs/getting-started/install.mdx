This page gets the Ravenswatch Mod Manager app onto your computer. It takes a few
minutes and you don't need to type any commands.

**Before you start**, make sure Ravenswatch is installed through Steam and that
you've started it at least once. RSMM works on **Windows 10/11**, **Linux** and
**Steam Deck**. macOS is not supported.

## 1. Download and install

All downloads are on the
[latest release page](https://github.com/Ovilli/RavenswatchModManager/releases/latest).
Scroll down to **Assets** and pick the file for your system.

<Tabs syncKey="os">
  <TabItem label="Windows" icon="seti:windows">
    <Steps>
    1. Download the file that ends in **`x64-setup.exe`**, for example
       `Ravenswatch.Mod.Manager_5.9.9_x64-setup.exe`. The version number will be
       whatever is newest.
    2. Double-click it and follow the installer.

       Windows may show a blue box saying **"Windows protected your PC"**. That
       happens with small projects that haven't paid for a code-signing
       certificate. Click **More info**, then **Run anyway**.
    3. Open **Ravenswatch Mod Manager** from the Start menu.
    </Steps>

    <Aside type="tip">
    If the app doesn't open at all, install
    [Microsoft WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
    (choose the *Evergreen Bootstrapper*) and try again. Windows 11 already has it.
    </Aside>
  </TabItem>
  <TabItem label="Linux" icon="linux">
    There are two choices. **If you're not sure, use the AppImage.** It works on
    almost every distribution and updates itself.

    **AppImage (recommended)**

    <Steps>
    1. Download the file that ends in **`.AppImage`**.
    2. Move it somewhere you'll keep it, such as `~/Applications`.
    3. Make it runnable. Right-click it, open **Properties → Permissions**, and
       tick **Allow executing file as program**. Or, in a terminal:
       ```sh
       chmod +x ~/Applications/Ravenswatch.Mod.Manager_*.AppImage
       ```
    4. Double-click it to start the app.
    </Steps>

    **Debian / Ubuntu package**

    Download the file that ends in **`.deb`** and open it with your software
    installer, or run `sudo apt install ./Ravenswatch.Mod.Manager_*_amd64.deb` in
    the folder you downloaded it to.

    A `.deb` install can't update itself. When an update comes out, the app
    offers a one-click **Install to ~/Applications**, which switches you over to
    a self-updating AppImage.

    **Arch Linux**

    There is an [AUR package](https://aur.archlinux.org/packages/rsmm):
    `yay -S rsmm`.

    <Aside type="caution">
    **Gray, empty window on Debian or Ubuntu?** Start the app from a terminal
    like this instead:
    ```sh
    WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 ./Ravenswatch.Mod.Manager_*.AppImage
    ```
    </Aside>
  </TabItem>
  <TabItem label="Steam Deck">
    <Steps>
    1. Hold the power button and choose **Switch to Desktop**.
    2. Open the release page in the browser and download the file that ends in
       **`.AppImage`**.
    3. Open the **Downloads** folder, right-click the file, open
       **Properties → Permissions** and tick **Is executable**.
    4. Double-click it to start the app.
    </Steps>

    Mods that change looks, numbers and text work on Steam Deck. Script (Lua)
    mods need one extra setting, explained in
    [Script mods on Linux and Steam Deck](#script-mods-on-linux-and-steam-deck).
  </TabItem>
</Tabs>

## 2. First start

When the app opens, it looks through your Steam libraries for Ravenswatch and
runs a quick health check. **If nothing pops up, everything is fine** and you
can skip to the next page.

If something needs fixing, a **First-run setup** box appears at the top of the
**Library** page and lists what's wrong:

<Steps>
1. If there's a button like **Repair 2 automatically**, press it. That fixes
   most problems.
2. If it says the game wasn't found, press **Open Settings** and fill in
   **Game install** with the folder that contains `Ravenswatch.exe`.

   Not sure where that is? In Steam, right-click **Ravenswatch** →
   **Manage** → **Browse local files**. The folder that opens is the one you
   want.
3. Go back to the **Library** and press **Re-check**. When every check passes,
   the box goes away.
</Steps>

You're ready. Go to [Using the app](/getting-started/desktop-app/) to install
your first mod.

## Updates

The app checks for new versions by itself. When one is ready you'll see a
message with a **Restart & update** button. That's all you need to do.

The app also keeps the **loader** (the small extra file that script mods need)
up to date in your game folder each time it starts.

## Script mods on Linux and Steam Deck

On Linux, Ravenswatch runs through Steam's Proton. Script (Lua) mods need Steam
to load RSMM's loader file, which takes one launch option:

<Steps>
1. In Steam, right-click **Ravenswatch** → **Properties**.
2. Under **General → Launch Options**, paste:
   ```
   WINEDLLOVERRIDES="winhttp=n,b" %command%
   ```
3. Close the window. Steam saves it automatically.
</Steps>

Script mods on Linux are still experimental. Mods that only change looks, numbers
or text don't need this.

## Uninstall

1. In the app, open **Commands** and run **Restore originals**. This puts every
   original game file back.
2. Uninstall the app the normal way: **Settings → Apps** on Windows, or delete
   the AppImage on Linux.

To be extra sure the game is clean, right-click Ravenswatch in Steam →
**Properties → Installed Files → Verify integrity of game files**.
