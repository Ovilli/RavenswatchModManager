## Play with mods

<CardGrid>
  <Card title="1. Install the app" icon="download">
    Download it for Windows, Linux or Steam Deck. No commands to type.
    [How to install →](/getting-started/install/)
  </Card>
  <Card title="2. Pick some mods" icon="magnifier">
    Browse mods shared by the community and install one with a single click.
    [Using the app →](/getting-started/desktop-app/)
  </Card>
  <Card title="3. Press Launch Modded" icon="rocket">
    The game starts through Steam with your mods switched on.
  </Card>
  <Card title="4. Back to normal any time" icon="approve-check">
    When you quit, RSMM puts the original game files back. **Launch Vanilla** plays
    without mods.
  </Card>
</CardGrid>

<CardGrid>
